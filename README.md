# Creator Channel Skills

> Audiogram and YouTube intro/outro skills for Claude Code — brand your channel and repurpose every episode into motion graphics.

## Install

```bash
npx skills add iart-ai/creator-channel-skills
```

Works with Claude Code + 40+ agents.

## What's included

| Skill | What it does |
|---|---|
| [audiogram](./audiogram) | Turn a podcast clip, voiceover, or quote into a captioned waveform video for Reels, TikTok, Shorts, and feed posts. |
| [youtube-intro-outro](./youtube-intro-outro) | Build a 3-5s branded intro sting and a 20s end-screen outro that respects YouTube's clickable element zones. |

## When it activates

- You ask to make an audiogram, turn a podcast into a video, or add a moving waveform to a voiceover.
- You want a square or vertical clip of a podcast quote for social.
- You ask to make a YouTube intro, channel bumper, or logo sting.
- You ask to design an outro, end screen, or end card with subscribe and next-video cards.
- You want a reusable brand template where only the name, logo, colors, and sting change.

## Example prompts

- "Make an audiogram from this 60-second podcast clip with captions, sized for TikTok."
- "Add a reactive waveform and a progress bar to my voiceover and export it 1:1 and 9:16."
- "Make a 3.5s YouTube intro where my logo snaps in on the audio sting."
- "Build an outro plate that leaves room for YouTube's subscribe and next-video elements."
- "Create a reusable intro/outro template I can re-skin per channel from a brand file."
